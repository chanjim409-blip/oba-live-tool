# 只读探针 SPA 稳定性

- 只读探针增加同一页面代次内的身份、当前房间和控件一致性检查；页面跳转或账号、房间变化时丢弃上一代观察，在同一已打开页面内等待新证据；不执行重载、额外身份请求或任何发送动作。
- 身份超过 30 秒拒绝输出；房间观察过期则标未知。验证码和权限拒绝立即停止，不重复请求或猜测已解除。
- 只统计上游 textarea 与 inputSuffix 的数量、可见/可编辑和 isDisabled 状态，不采集或打印任何页面文本。仅作为控件候选，不推导达人角色或发送权限。
- 探针在启动浏览器前必须经宿主的认证接口确认没有持久停刷；旧宿主/接口不可用时拒绝启动。探针观察到限制后交由宿主持久记录，报告失败立即停下并提示；独立进程不直接写宿主数据库。
- 测试覆盖页面等待/读取期间跳转、旧账号和房间不得混入、验证码与权限拒绝停止、过期身份/房间；仅使用合成对象，不触达平台和登录凭据。
- 这是只读探针稳定性改进，不等于身份角色字段已确认或真实发送链路已接通；仍需现场只读核验和用户确认后才能发送。
