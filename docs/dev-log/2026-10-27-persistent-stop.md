# 百应停刷状态持久化与身份代次

- 百应登录失效、权限拒绝、限频和平台验证状态写入宿主私有 SQLite，并在重启时于启动任何采集或独立回复浏览器前读取。停止原因和固定审计事件不含账号、弹幕或凭据。
- 停止状态存在时，身份读取、发送、刷新和手动验证入口保持拒绝，避免切换路径继续访问平台；health 保留可读状态。进程内写入失败时锁存存储故障并停止，存储异常修复前不能用重启视为解除。
- 认证保护的本机 `GET /collector/restriction` 只返回状态，`POST` 只接受四种固定停止原因并持久上报；无清除入口。只读探针经该接口通信，宿主是唯一数据库写入者。
- 保留 `login_user_id` 为不透明观察字段，将变化纳入身份代次并废弃旧房间数据，不推定其含义或证明达人身份。界面按钮 class 存在 isDisabled 时拒绝发送。
- 离线测试覆盖关闭重开数据库仍阻止浏览器启动、已认证上报/禁止清除、无凭据上报拒绝、身份探针与其他路线的限制、非法数据拒绝、存储失败保护、仅登录字段变化及禁用类名。无真实平台发送或部署。
- 人工解除流程尚未开放：需由用户人工处理平台提示后，再设计经明确授权、保留审计且要求重新核验的恢复流程；重启不能自动解除。存储无法写入时本进程保持停止，但不能保证无法写入时跨断电形成记录，须先处理存储故障。
- 追加修复：没有采集器时探针上报遇到存储写入失败，宿主先设置内存故障锁并关闭独立回复浏览器；任何身份核验、刷新与发送都返回固定错误。读取错误和启动时异常同样不暴露原始错误；可写时用独立固定内容标记让重启也保持停止，不能自动清除。如果数据库和整个卷都无法写入，无法保证停刷跨断电形成记录，需先修复存储。
- 回复预检查同时拒绝 `disabled`、`aria-disabled=true` 和 `isDisabled` 类名；离线宿主回归 52/52，类型检查通过。
