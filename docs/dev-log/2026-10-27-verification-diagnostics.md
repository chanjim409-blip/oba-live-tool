# 人工验证后复核失败的原因区分

真实观察：用户完成滑块，并确认重新打开的可见直播间正常、无滑块。761a365宿主返回身份/房间/管理员匹配，但人工完成接口报复核失败；没有发送。此时不能声称存在新的平台验证码。

发现确定代码问题：completeManualVerification把任何失败写成restricted=true，包括聊天输入框尚未挂载等本地错误，混淆了原因。

修复：保持manualState=blocked禁止执行，但仅由实际平台检测设置restricted；分别报告manualFailure中的未开播、身份不符、管理员未证明、控件不可用、平台限制或其他失败。等待输入框可见最多5秒后复核，不刷新重试、不弱化身份或验证码检查。

新增受现有认证保护的GET /reply/diagnostics：只读取当前页面控件数量/可见/可编辑及验证码候选数量，最多2秒；不导航、不返回文字/弹幕/身份标识、不点击。常规preflight仍不读DOM。

回归24/24及typecheck通过，新增控件不可用不误标平台限制、诊断只返回聚合字段。失败真因仍待新版真实诊断，不能把可能的输入框加载延迟写成已证实根因。尚无真实发送或观众确认。
