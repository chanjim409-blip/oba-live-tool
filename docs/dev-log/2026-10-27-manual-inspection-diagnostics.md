# 人工查看入口失败诊断

- 本机尝试打开人工查看窗口后只得到 `bridge_inspection_open_failed`，运行版本没有记录失败发生在哪一步；不能据此断言是账号受限、浏览器占用、登录过期或页面问题。
- 新增固定、脱敏的失败阶段：配置、资料路径、占用检查、独占租约、启动浏览器、创建页面、官方页面加载和窗口显示等。只在发生故障时由已有认证接口返回固定阶段码，不输出账号、路径、页面内容、异常原文或凭据。
- 开窗失败仍保持失败状态，不自动重试；平台停刷仍持久保持，发送开关和恢复门禁均不变。此修改不会自动修复或重开已运行的旧版本。
- 合成测试覆盖浏览器启动失败、导航失败、HTTP 响应脱敏、失败后禁止重试以及停刷不清除；宿主 67/67、类型检查和协议 4/4 一致。未访问真实平台、启动或重启服务。
- 只有在用户后续明确安排并完成安全部署后，新版本才可能提供失败阶段证据；不应据此自动绕过占用检查或平台限制。
