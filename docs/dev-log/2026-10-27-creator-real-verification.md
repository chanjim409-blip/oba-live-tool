# 达人登录与真实只读核验

- 用户确认登录页在新标签打开达人首页；原登录助手仅观察原标签，故未导出。用户在原标签进入百应中控台后，助手已将新的会话保存至系统私有目录；会话不进入 Git。
- 修改登录助手以观察同一自有 context 中的新标签，仅在无可见验证、处于指定百应中控页及页面标记存在时导出；不覆盖旧会话，报告不保存原始昵称或 URL 查询参数。当前运行中的旧进程没有热更新。
- 独立无头宿主只读探针曾从达人会话的页面响应读到身份字段与部分数字取值，但官方含义、角色与执行者的映射尚未证明；不得据此写入 verified 或启用发送。控件第一次检查为空；等待页面渲染后又遇到页面代次变化，已停止重复导航/刷新。当前未确认平台限制，也不将未知当作已解除或已接通。
- 未核实角色时服务硬阻断真实百应发送开启；即使配置任意 getUser 字段和值也不能绕过。完整链路真实单次发送与观众确认仍未发生。
- getUser/playinfo 返回 401、403、429 或验证码时，失效相关身份并停止本进程后续刷新，明确错误；关闭自有采集页面。锁存当前仅在进程内，重启会丢失，不能视为人工解除。上线前需补跨进程持久化以及经人工核查的恢复流程。
- 原生 @、平台回执、角色字段含义、发送控件及当前直播房间仍待核验。性能方面，单次动作可能重复刷新身份和房间，需有时间预算实测并减少无意义重复调用，保留执行前复核。
- 仅对代码运行离线测试，未更换运行服务、未修改 NAS、未发送。助手场次仍需按真实当前状态核实，不根据历史结果推断。
